# The Northerner Diaries — optional game soundtrack

Place legitimately obtained MP3 recordings in this directory, named `01.mp3` through `12.mp3` in album order. Do not upload a ZIP, streaming-service downloads with DRM, or unrelated music. No recordings are supplied by this repository change. Until playable files are available the original procedural soundtrack remains the fallback.

Music: The Northerner Diaries – Symphonic Sketches by Jeremy Soule. Copyright remains with the rights holder.
