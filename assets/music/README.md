# Game music

Upload any authorized audio directly into this folder on development. Keep original filenames; any number of tracks is allowed. MP3 is recommended; OGG, WAV, M4A, AAC, FLAC and Opus are discovered, with playback dependent on browser codec support. Subfolders are optional. The approved Vercel build generates playlist.json automatically. For local static testing, run `node scripts/generate-music-playlist.mjs` before serving the game. No tracks are bundled by this change. Keep artist, title, rights holder and permission records here for each addition. Do not upload music without permission for public hosting and game distribution.
