## Generation prompt

Use case: stylized-concept. Asset type: a single production sprite atlas for Crown & Kingdoms, an original hand-painted medieval isometric real-time strategy game. Create ONE transparent-background resource atlas, 1536x1024 landscape, strict 3 columns by 2 rows equal cells, generous empty transparent padding within EACH cell, no overlap across cells. Top row: left a compact low cluster of angular cool GREY GRANITE STONE boulders; middle a compact dark brown-grey rock outcrop with clearly visible natural warm GOLD ORE VEINS and gold mineral chunks, no coins; right one lush rounded GREEN BERRY BUSH with many clearly visible dark crimson red berries and a few woody stems. Bottom row: second distinct natural silhouette variant of the same stone cluster, gold ore deposit, berry bush in same order. Each object centered in its own cell with the same ground baseline and comparable width. 3/4 isometric strategy camera, upper-left warm daylight, detailed painterly pre-rendered textures, grounded low silhouettes, transparent cutout edges and subtle soft contact shadows. Objects occupy roughly 65-75% of cell width, stay completely inside cells including shadows. Stone should look like mineable rock not crystals; gold has distinctive ochre-yellow seams embedded in dark stone; bush must look like edible red fruit foliage not a tree. Realistic medieval RTS artwork, readable at 48-64 gameplay pixels, matches textured grassy terrain and hand-painted stone/timber buildings. No text, labels, grid lines, symbols, tools, people, buildings, terrain squares, UI, watermarks or pixel art.
