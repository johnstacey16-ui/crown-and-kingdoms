A versioned catalogue covers all 56 active WebPs (55 atlases and terrain); the worker embeds a digest of that complete catalogue. An image changed at the same URL changes the catalogue and worker bytes. Up to four image checks/downloads run concurrently. Code and JSON are fetched afresh during installation; HTML/JS/CSS/JSON retain their existing network-first fetch behavior.

This is content verification for cache correctness, not a replacement for HTTPS or a security guarantee against a compromised origin.
